# Radar Noticias
Reporte automático de noticias de Blu Radio, Caracol Radio y La FM para la Oficina del Diputado Felipe Ferro.
Se actualiza a las 6:00, 6:30, 7:00, 7:30, 8:00 y cada hora hasta las 10:00 pm. Página: https://noffaldaniels.github.io/radar-noticias/
Pruebas: `python -m pytest -q`. Correr a mano: `python -m radar`.
